# dark-tech

**Mood:** futurista, AI/dev, sperimentale
**Use case:** dev tool, AI/ML product, tech research, internal demo, cyberpunk-vibes pitch

## Cifre stilistiche
- **Tipografia**: monospace per titoli (JetBrains Mono, Space Mono) + tech sans body (Inter/IBM Plex Sans). Pesi 400/500/700.
- **Decorazioni**: base near-black + 1 neon accent, scanline/grid pattern, glow effects sui dot/accenti, subtle glitch/flicker.
- **Motion**: micro-glitch sui titoli, terminal-style typing per i numeri.
- **Borders**: 0-4px sharp, neon outline su hover.
- **Background**: near-black + grid sottile o scanlines.

## Palette default
- brand-1: `#00FF94` (neon green)
- brand-2: `#0EE6F0` (cyan accent)
- brand-3: `#1E2236` (panel)
- brand-4: `#0A0E1A` (deep)
- soft-1:  `#141826`
- soft-2:  `#252B3E`

## Quando NON usarlo
- Pitch consumer / community → `playful`
- Doc formali → `corporate`
- Brand creativi soft → `editorial`
