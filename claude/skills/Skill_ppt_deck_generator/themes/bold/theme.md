# bold

**Mood:** confident, brutalist-lite, energico
**Use case:** pitch start-up, product launch, hackathon, manifesto, eventi

## Cifre stilistiche
- **Tipografia**: sans **black/heavy** (Inter 800/900, Archivo Black), oversize.
- **Decorazioni**: blocchi di colore pieni, bordi spessi 4-5px, forme geometriche (cerchi, quadrati), **no gradient, no orbs**.
- **Motion**: transitions sharp, scaling forte.
- **Borders**: 0px (sharp) o 24px (pillole). Mai medi.
- **Background**: blocchi di colore solido che si alternano.

## Palette default
- brand-1: `#FF3D00` (red-orange impattante)
- brand-2: `#FFEA00` (yellow vivido)
- brand-3: `#0D0D0D` (near-black)
- brand-4: `#0D0D0D` (dark bg = stesso)
- soft-1:  `#FFFFFF`
- soft-2:  `#F5F5F5`

## Quando NON usarlo
- Doc formali / board (troppo aggressivo → `corporate`)
- Brand vision premium (troppo "stridente" → `editorial`)
