# playful

**Mood:** friendly, vibrante, umano
**Use case:** comms interne, education, community, consumer brand, kids/family

## Cifre stilistiche
- **Tipografia**: sans rounded (Nunito, DM Sans, Poppins), pesi 400/600/800.
- **Decorazioni**: forme arrotondate (blob, cerchi), mix multi-color (rosa+giallo+verde+blu), animazioni bouncy.
- **Motion**: spring/bounce, leggera rotazione, hover scale.
- **Borders**: 24-32px (molto arrotondati) o cerchi pieni.
- **Background**: gradient pastello o solid color saturi.

## Palette default
- brand-1: `#FF6B9D` (rosa)
- brand-2: `#FFD93D` (giallo)
- brand-3: `#6BCB77` (verde)
- brand-4: `#1A1B3A` (deep blu-viola per dark)
- soft-1:  `#FFF0F5`
- soft-2:  `#4D96FF` (blu accent)

## Quando NON usarlo
- Pitch formali → `corporate`
- Doc tecnici → `minimal`
