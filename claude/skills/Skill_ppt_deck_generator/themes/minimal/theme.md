# minimal

**Mood:** preciso, tecnico, "Swiss"
**Use case:** doc tecnici, white paper, ricerca, presentazioni accademiche, data

## Cifre stilistiche
- **Tipografia**: grotesk pulito (Inter/Helvetica), pesi 400/500/700. Numeri **monospaced** (JetBrains Mono o sans-mono).
- **Decorazioni**: nessuna. Linee 1px sharp, griglia visibile, **zero gradient**, zero ombre.
- **Motion**: solo fade opacity, durata breve.
- **Borders**: 0–4px (poco arrotondamento), separatori 1px.
- **Spaziatura**: generosa, uso forte della griglia.

## Palette default
- brand-1: `#000000` (text + primary)
- brand-2: `#1A1A1A`
- brand-3: `#666666`
- brand-4: `#FAFAFA` (alt bg)
- accent:  `#0066FF` (l'unico colore — usato con parsimonia)

## Quando NON usarlo
- Pitch creativi / brand vision (manca personalità → `editorial`)
- Eventi consumer (troppo freddo → `playful`)
